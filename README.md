# FunPay Helper

**Готовые ответы для чатов FunPay — рядом с полем сообщения.**

Создавайте шаблоны для частых вопросов и вставляйте нужный текст в переписку одним нажатием. Расширение не отправляет сообщения автоматически: перед отправкой вы можете проверить и изменить текст.

## Возможности

- Создание, редактирование, поиск и удаление шаблонов.
- Компактная кнопка «Шаблоны» в чате и быстрый выбор ответа.
- Необязательная категория для удобного поиска.
- Настройка показа кнопки в чате.
- Резервное копирование и восстановление шаблонов и настроек.
- Интерфейс, адаптированный под светлую и тёмную тему сайта и разные размеры экрана.

Доступны только реализованные функции. Управление лотами, быстрые действия и статистика в эту версию не входят.

## Установка

1. [Скачайте последнюю версию](https://github.com/unknokable0/FunPay-Helper/releases/latest) и распакуйте архив в постоянную папку.
2. Откройте страницу расширений: `brave://extensions`, `chrome://extensions` или `edge://extensions`.
3. Включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
4. Выберите папку **FunPay-Helper**, в которой находится `manifest.json`.
5. Откройте или обновите FunPay. Пункт **FP Helper** появится в шапке сайта.

> Для установки не выбирайте сам ZIP: браузеру нужна распакованная папка.

## Как пользоваться

1. Откройте **FP Helper** на сайте FunPay и создайте шаблон: укажите название и текст.
2. В переписке нажмите **«Шаблоны»** рядом с полем сообщения и выберите ответ.
3. Проверьте текст и отправьте сообщение самостоятельно.

Показ кнопки можно отключить в разделе **Настройки**.

## Обновление и сохранение данных

Перед обновлением откройте **FP Helper → Настройки → Резервная копия → Скачать копию**. Файл может содержать личные тексты — храните его в безопасном месте.

Для обновления замените файлы в **прежней папке** расширения, нажмите кнопку обновления на странице расширений и обновите FunPay. Не удаляйте расширение: при удалении браузер может удалить его данные. При переустановке или переходе в другой браузер используйте **«Восстановить из файла»**; восстановление заменяет текущие шаблоны и настройки.

Распакованное расширение может проверять доступность новой версии, но **не устанавливает обновления автоматически**. При установке из магазина браузера действуют правила обновления этого магазина; версия в магазине пока не опубликована.

## Данные и конфиденциальность

Шаблоны и настройки хранятся локально в хранилище расширения текущего профиля браузера. Они не синхронизируются автоматически. Расширение обращается к GitHub для проверки версии; шаблоны туда не отправляются.
