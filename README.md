# FunPay-Helper

Расширение для Brave / Chrome. Добавляет на FunPay кнопку **FP Helper** в шапку (рядом с Lite Bot) и меню с функциями.

## Как установить

1. Нажми **Code → Download ZIP** и распакуй архив.
2. Открой `brave://extensions`.
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение** и выбери распакованную папку.

## Как обновить

Расширение само проверяет GitHub раз в 6 часов. Если вышла новая версия, на кнопке FP Helper появится розовая точка, а в меню кнопка **Скачать**.

1. Скачай ZIP и распакуй **поверх старой папки** (с заменой файлов).
2. В `brave://extensions` нажми значок ⟳ у FunPay Helper.
3. Обнови страницу FunPay.

## Функции

- Шаблоны в чате: кнопки над полем ввода. Нажал, и текст вставился. Отправляешь ты сам. Тексты меняются в меню (Изменить шаблоны).
- Проверка обновлений.
- Скоро: копирование лотов, сообщение после заказа, статистика продаж.
