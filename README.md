# FunPay-Helper

Расширение для Brave / Chrome. Добавляет в чат FunPay кнопки с готовыми шаблонами сообщений.

## Как установить

1. Нажми **Code → Download ZIP** и распакуй архив.
2. Открой `brave://extensions`.
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение** и выбери распакованную папку.

## Как пользоваться

- Открой чат на funpay.com. Над полем ввода появятся кнопки.
- Нажал кнопку, и текст вставился в поле. Отправляешь ты сам.
- Свои тексты: нажми на иконку расширения, измени шаблоны и нажми **Сохранить**.
