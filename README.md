# FunPay Helper

> Набор инструментов для продавцов FunPay: быстрые ответы, перевод лотов, список заказов и напоминания об отзыве.

**Версия:** `0.9.31` · **Браузеры:** Chrome, Chromium, Brave, Edge · **Формат:** Manifest V3

[Быстрый запуск](#быстрый-запуск) · [Возможности](#возможности) · [Данные-и-разрешения](#данные-и-разрешения) · [Тесты](#разработка-и-тесты) · [История изменений](CHANGELOG.md)

## Быстрый запуск

1. Нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте страницу расширений: `chrome://extensions`, `brave://extensions` или `edge://extensions`.
3. Включите **Режим разработчика**.
4. Выберите **Загрузить распакованное расширение** и укажите папку `FunPay-Helper-main` — в ней должен лежать `manifest.json`.
5. Обновите вкладку FunPay. Панель **FP Helper** появится в шапке сайта.

Подробные шаги и инструкция по обновлению — в [INSTALLATION_RU.md](INSTALLATION_RU.md).

## Возможности

| Инструмент | Что делает | Важное поведение |
| --- | --- | --- |
| **Быстрые ответы** | Поиск, категории и избранные шаблоны; избранное показывается первым в меню чата | Текст вставляется в поле — сообщение отправляете вы сами |
| **Перевод лота** | Переводит заполненные русские поля на английский | Запускается кнопкой; перевод нужно проверить и опубликовать вручную |
| **Свои лоты** | Подсвечивает ваши объявления в списке | Имя продавца настраивается |
| **Список заказов** | Показывает оплаченные заказы и позволяет скопировать их номера | Просмотр без подтверждения или изменения заказов |
| **Напоминание об отзыве** | Очередь показывает статусы заказов и готовые сообщения | Для новых установок по умолчанию требуется подтверждать каждую отправку; автоматический режим можно включить отдельно |
| **Резервная копия** | Экспортирует и восстанавливает шаблоны и настройки | Перед заменой данных показывает настройки и примеры шаблонов из файла |
| **Проверка версии** | Показывает, доступна ли новая версия | Проверяет версию, но не скачивает и не устанавливает обновление автоматически |

> Функция генерации текста лота с помощью AI удалена в версии `0.9.30`. При обновлении расширение очищает сохранённые настройки этой функции.

### Работа с напоминаниями

Новые установки используют ручной режим: после задержки и проверки заказа сообщение появляется в очереди. Нажмите **Подтвердить отправку**, проверьте текст и подтвердите действие. Перед отправкой заказ проверяется повторно. Можно пропустить отдельный заказ.

Если в предыдущей версии у вас уже была включена автоматическая отправка, обновление сохраняет этот режим. Переключить режим можно в разделе **Напоминание**.

## Обновление

1. В **FP Helper → Резервная копия** сохраните шаблоны и настройки.
2. Скачайте свежий ZIP репозитория и распакуйте его.
3. Замените файлы в **той же папке**, из которой загружено расширение.
4. На странице расширений нажмите **Обновить** у FP Helper и перезагрузите вкладку FunPay.

Не удаляйте расширение и не переносите его папку: так можно потерять локальные данные и очередь напоминаний.

## Данные и разрешения

- Шаблоны, настройки и очередь напоминаний хранятся локально в профиле браузера.
- При нажатии **Перевести** текст лота отправляется в Google Translate для обработки. Не переводите конфиденциальные данные.
- Проверка заказов и включённые напоминания обращаются напрямую к FunPay от имени вашей авторизованной сессии. Напоминание отправляется покупателю автоматически только если вы включили эту функцию и настроили текст.
- Проверка версии читает `manifest.json` в этом репозитории через GitHub. Автоматической установки нет.
- Расширение не использует собственный сервер. Оно не отправляет шаблоны автору проекта.
- Ручное подтверждение напоминаний включено по умолчанию на новых установках. Старые включённые настройки автоматической отправки сохраняются при обновлении.

Для работы расширению нужны разрешения Chrome `storage`, `alarms`, `offscreen`, `clipboardWrite`, а также доступ к `funpay.com`, `raw.githubusercontent.com` и `translate.googleapis.com`.

**Ограничение напоминаний:** FunPay может не показывать ID автора отзыва в доступной истории. Для некоторых старых отзывов стопроцентная проверка невозможна. Если результат отправки неоднозначен, расширение не повторяет отправку автоматически — проверьте чат вручную.

## Разработка и тесты

Требуется Node.js. Из корневой папки репозитория запустите:

```bash
node --test tests/*.test.cjs
```

Проверка синтаксиса JavaScript:

```bash
for file in ./*.js; do node --check "$file"; done
```

Основные файлы расширения находятся в корне, потому что пути к ним указаны в `manifest.json`. Тесты — в `tests/`, подробная история изменений — в `CHANGELOG.md`.
