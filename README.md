# FunPay Helper

Лёгкое расширение для Chrome и Chromium-браузеров. Кнопка **FP Helper** в шапке FunPay открывает раздел расширения прямо в текущей вкладке, сохраняя шапку сайта. Другие разделы FunPay открываются обычным способом; кнопка «Назад» возвращает предыдущую страницу.

## Установка и обновление

1. Скачайте ZIP из GitHub и распакуйте в постоянную папку (не запускайте из архива).
2. Откройте `chrome://extensions` или `brave://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
4. Откройте или обновите страницу FunPay.

Для обновления замените файлы в той же папке и нажмите ⟳ на странице расширений, затем обновите FunPay. Не удаляйте установленное расширение: при удалении браузер может удалить связанные локальные данные. Рекомендуется заранее скопировать важные шаблоны. При локальной загрузке перенос данных сохраняется, если ID расширения не изменился (обычно при сохранении прежней папки и установки). Новая независимая установка может иметь другой ID и отдельное хранилище.

## Возможности

- Создание, редактирование, удаление и локальное хранение шаблонов. Необязательная категория хранится вместе с шаблоном.
- Переключатель кнопок шаблонов в чате. Кнопки вставляют текст; пользователь сам отправляет сообщение.
- Проверка обновлений через GitHub каждые 6 часов и вручную в настройках; индикатор новой версии в шапке и на значке расширения.
- Разделы лотов, быстрых действий и статистики обозначены как не реализованные. Автоматизация заказов и статистика не заявляются рабочими.

Не передаёт данные FunPay на сторонние серверы: запросы к GitHub используются только для проверки версии. Данные шаблонов хранятся в `chrome.storage.local` данного профиля браузера, не синхронизируются автоматически и не являются резервной копией.
